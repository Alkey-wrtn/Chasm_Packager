# ChasmCopyPackager 2.0.0
캐즘 카피 JSON 폴더/디렉토리화

1. "결정화 캐즘 네오카피"(https://github.com/milkyway0308/crystallized-chasm/)를 통해 복사한 캐릭터의 "JSON"을 파일로 저장해줘요.(복사된 json을 아무 폴더에다가 .json 형식의 파일로 저장해주세요.)

2. ChasmCopyPackager.exe를 실행하고, [JSON 파일 선택] 버튼을 눌러 아까 저장한 .json 파일을 불러와줍니다.

3. [저장될 폴더 선택]을 눌러 어느 경로에 최종적으로 저장될 것인지 선택해요.
3-1. 만약에 저장할 폴더 이름이 "Crack"이라면, 캐릭터 파일 저장 경로는 "Crack/{캐릭터명}"이 될 거에요.

4. [실행]을 누르고 기다리기만 하면 끝!

## 변경사항
- 2.0.0: 25년 12월 22일자 크랙/캐즘 업데이트에 대응했어요, 사실 1.1.0버전 이후로 사실상 업데이트 안 하고 있었는데, 스탯이랑 엔딩 기능, 플레이 가이드부터 이것저것 추가된 것에 다 대응되도록 업데이트 했으면서도 2.X.X 버전에서도 이전 버전의 json과 호환되도록 해 봤어요.
